# The 8 Phases at a Glance

1. **Foundation** — Auth, Spatie RBAC, dynamic sidebar nav, user/settings/lookups management (start here)

2. **Catalog** — Categories (nested) + Products with image upload

3. **Inventory** — Append-only stock ledger, manual adjustments, low-stock alerts

4. **POS** — Single-screen checkout, stock deduction on sale, PDF receipt

5. **Storefront** — Public listing, cart, guest checkout, order confirmation email

6. **Finance** — Expenses, sales ledger, profit report, PDF/CSV export

7. **Polish** — Tests, audit trail, demo seed data, deployment prep
